feat: panel page for pointing other AI tools at this gateway

Adds the UI for the provider-switching backend: a "客户端接入" page listing
Claude Code, Codex CLI and Gemini CLI, each showing whether it is installed and
whether it currently points at this gateway.

Actions per client:

  - 接入本网关        write this gateway into that tool's own config file
  - 还原原始配置      put the file back from the backup taken on first write
  - 预览改动          show the file and the before/after values first

Backend endpoints, all gated on the panel password rather than an API key,
because they write configuration outside this program's own data directory:

  GET  /providers              each client's state
  GET  /providers/preview      what applying would change
  POST /providers/apply        point a client at the gateway
  POST /providers/revert       restore from the backup

Verified over real HTTP: the routes reject an unauthenticated caller with 401,
list all three clients once signed in, resolve the preview correctly, and a full
apply/restore round trip preserves the user's own settings.
